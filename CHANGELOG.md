# Changelog

## 1.0.0 — Initial source implementation

- Created original offline gallery/player Android project.
- Added MediaStore access, gallery filtering, folders, search, sorting and thumbnails.
- Added Media3 playback surface, queue navigation, seek, repeat, speed, track dialogs, external subtitle selection, aspect ratio and view rotation controls.
- Added left/right adjustment gestures and center-zone vertical navigation with pure unit-testable classification.
- Added local settings, privacy/build documentation and CI workflow.
- Build and device validation remain blocked by the current host environment; see `BUILD_REPORT.md`.
